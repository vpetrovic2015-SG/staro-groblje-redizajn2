# Старо гробље Пожаревац — дигитални водич

Редизајнирана GitHub Pages верзија у историјском стилу: тамна графитна заглавља, златни детаљи, крем панели, каталог личности са портретима, биографије, QR кодови, мапа и планирани 3D приказ споменика.

## Објављивање на GitHub Pages
1. Направите резервну копију тренутног репозиторијума.
2. Распакујте ZIP локално.
3. Отпремите садржај у корен репозиторијума, уз очување фасцикли `assets/` и `data/`.
4. У GitHub-у отворите **Settings → Pages** и проверите да се објављује из гране `main` и фасцикле `/ (root)`.
5. Сачекајте да GitHub Pages заврши објављивање, па тестирајте претрагу, филтере, биографије, QR кодове, мапу и избор писма.

## Структура
- `index.html` — странице и секције
- `styles.css` — прилагодљиви визуелни стил
- `app.js` — претрага, филтери, профили, QR кодови и мапа
- `data/licnosti.json` — подаци о личностима
- `assets/licnosti/` — портрети
- `assets/grobna-mesta/` — фотографије гробних места

## 3D модели
Секција „3D приказ“ је тренутно визуелна најава функције. Интерактивни модели нису додати док не буду припремљени и извезени из Meshy.ai у формату GLB/glTF. Тада ће се модел додати као посебна датотека у `assets/3d/` и повезати са одговарајућим записом личности.

Спољне библиотеке Leaflet и QRCode.js учитавају се са CDN-а, па за њихов рад је потребна интернет веза.
